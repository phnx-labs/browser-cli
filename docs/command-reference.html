browser CLI command reference

Drive real browsers with their profiles and cookies from the command line. Agents use a persistent task to navigate pages, inspect elements, interact with forms, capture screenshots and network traffic, then close the task. A local IPC service manages browser processes and tabs, using Chrome DevTools Protocol, Firefox WebDriver BiDi or native Arc control; tasks can also run on another machine over SSH.

browser profiles

Manage browser profiles

Options

FlagsDescriptionChoicesDefault
-h, --helpdisplay help for command

Examples

# WHERE is the devices whose own file declares the name
browser profiles list

# Create one on this device
browser profiles add work --browser chrome
browser profiles create work --browser chrome

# Claim leftover central profiles on the machine that hosts the browser
browser profiles claim
browser profiles claim comet-local

# Clean up dead ones this device declares: check first, then apply
browser profiles prune --dry-run
browser profiles prune

# Make one the machine's default for a bare `browser start`
browser use work

# Which profiles are signed in to which service, and as whom
browser profiles logins
browser profiles logins --json   # [{"profile","service","account"} | {"profile","service":null,"account":null,"unread"}]

Notes

A device declares its own browsers in its own `browser/profiles/<machine>.yaml`. A name declared by exactly one device is identity-bearing; a name declared by several is fungible. Leftover central `browser:` entries are claimed with `browser profiles claim` on the machine that hosts the browser. In `list`, the `*` marker means "this machine's configured default" (`browser start` with no --profile). A profile a setup wizard pins is named `auto-chrome`; `default` is only an ALIAS for whichever profile this machine is configured to use, resolved the same way by every command. `prune` only considers profiles this device declares. It never removes a profile that is in use, the configured default, or the `auto-chrome` profile a setup wizard created. On a Mac with Arc, every Arc Space is listed as a profile (arc-home, arc-work, ...) discovered read-only from Arc's own metadata — a Space already carries its Arc profile's logins, so it IS the browser profile. Agents attach to the running Arc through Apple Events and never launch or relaunch it; their tabs open in an Arc window of their own. Comet's own profiles are listed the same way (comet-work, ...), pinned to Comet's real user-data dir, so agents and you share one Comet window per profile: agents attach when it is running with remote debugging, launch it on your store when it is not running, and fail loud with the relaunch command when it runs without a port. The daemon publishes every discovered profile into this device's declaration, so other fleet boxes list it with WHERE=<this device> and route to it. Point agents at Comet when a workflow needs downloads, network capture, or trusted input: browser profiles create agents-comet --browser comet --attach-only A CDP `--attach-only` profile attaches to a browser you already started with remote debugging and fails loud with the relaunch command otherwise, pinned to a durable --user-data-dir so the sign-in survives quit+relaunch. A foreign browser squatting the canonical port is rejected, not driven — `browser profiles doctor <name>` flags it.

Keep one process and daemon IPC socket open; read NDJSON requests from stdin and write NDJSON responses

Options

FlagsDescriptionChoicesDefault

Examples

# Batch two warm actions through one process and one browser-service connection
printf '%s\n' \
  '{"action":"screenshot","path":"/tmp/page.jpg"}' \
  '{"action":"click","atX":320,"atY":540}' \
  | browser stream --task "$AGENTS_BROWSER_TASK"

# Keep the command open and send one JSON object per line from a long-lived shell
browser stream --task "$AGENTS_BROWSER_TASK"

Notes

stdout is protocol-only: one compact JSON response for each non-empty input line. Malformed JSON returns an error response without closing the stream. The first start response becomes the default task for later lines in the same stream.

# Use cases

Each page shows a real run: the task, the commands the agent ran, and what came back.

- [Set up in a minute](set-up-in-a-minute.md): install, create a profile and list a page's clickable elements
- [Keep work and personal apart](work-and-personal-profiles.md): each profile keeps its own logins
- [Research papers and sources](research.md): pull the numbers out of a long paper in a few lines
- [Check a page on a phone](check-on-a-phone.md): emulate an iPhone or iPad and screenshot the layout
- [Download files](download-files.md): wait for the file on disk and get its path back
- [Keep proof of what it did](keep-proof.md): recordings, PDFs and screenshots saved per task
- [Fill forms and check out](fill-forms-and-check-out.md): type by label, pick options and click by name
- [Use the sites you are signed into](signed-in-sites.md): work in tools that have no API or MCP server
- [Several agents, one browser](several-agents.md): each task owns its tabs
- [Design in Figma](design-in-figma.md): shortcuts, clicks at a position and the properties panel
